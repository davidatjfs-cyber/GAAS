# 黄金基准集草稿 v1（20 个真实案例，待专家确认）

> 用途：作为数字孪生引擎的判卷标准（Ground Truth）首批素材。
> 状态：案例已从真实桌访/差评选出，**四层标注待业务专家/店长逐条确认**。
> 确认方式：对每个案例补「标准情绪曲线 / 标准吐槽 / 不能说的话 / 点菜行为 / 推荐接受率 / 最终满意拆解 / 最终行为 / 专家解释」，或直接回复"该案例合格/不合格/删除"。

## 一、每组 Case 的四层标注结构（判卷标准模板）

| 层级 | 内容 | 用途 |
|---|---|---|
| L1 行为层 Behavior | 点菜、等待、催菜、结账、评价等客观行为 | 训练行为一致性 |
| L2 心理层 Psychology | 每一步情绪/满意度/信任连续变化（禁止跳变） | 训练内部状态 |
| L3 语言层 Language | 每个阶段最符合真人的表达与措辞 | 训练说人话 |
| L4 判卷层 Evaluation | 为什么合理、哪些回答算合格/失真 | 自动评估质量 |

每组 Case 固定结构：

```
case_id / title / difficulty / purpose
├─ 客户人格（visit/intent/price/service/environment/food/expression/complaint/recovery）
├─ 消费背景（时间/人数/首访复访/渠道/预算/目的）
├─ 消费目标（聊天/拍照/体验/安静…）
├─ 事件时间轴 Timeline（进店→落座→点菜→上菜→催菜→处理→买单）
├─ 每一步心理变化（情绪连续曲线 85→74→61…，不允许跳变）
├─ 标准反馈（分阶段：第一次委婉→第二次质疑→第三次取消→沉默）
├─ 标准吐槽（真实表达，不是"菜慢"）
├─ 不能说的话 negative（禁止戏剧化：报警/曝光/辱骂/突然离店）
├─ 点菜行为（浏览→问招牌→问分量→犹豫→接受/拒绝推荐）
├─ 推荐接受率（服务员推荐什么接受/拒绝）
├─ 补偿恢复（每次动作恢复值；恢复不超原始损失）
├─ 最终满意（拆分明细：菜/服务/环境/等待/补偿→总分）
├─ 最终行为（是否投诉/点评/星级/复购/推荐）
└─ 专家解释（为什么是这个结果）
```
