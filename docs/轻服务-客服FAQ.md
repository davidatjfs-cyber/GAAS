# 客服 FAQ（健康中心红项深链）

> 与 `server/services/tenant-health-faq.js` 保持同步。目标：常见问题自助解决，减少重复答疑。

## data-not-updated · 为什么数据没有更新？

1. 看健康中心「昨日订单是否同步」与最近同步时间  
2. 若 POS 未接入：先完成订单接入，不是客服改数  
3. 若接入正常但昨日为 0：核对门店是否休息、时区、门店编码映射  
4. 飞书多维表/同步任务失败时，属平台或第三方，按责任方升级  

## phone-match-low · 为什么手机号匹配率低？

1. POS 订单本身未带手机号（采集流程问题，需门店/POS 侧改）  
2. 小程序未授权手机号，会员库与 POS 对不上  
3. 匹配率 &lt;60% 时自动营销与归因不可靠，优先催采集而不是加功能  

## attribution-low · 为什么营销归因少？

1. 触达未带 campaign_id  
2. 券核销未回写订单  
3. 手机号匹配率低导致无法识别同一客户  
4. 归因窗口内客户未回店（这是经营结果，不是系统坏了）  

## sms-not-sent · 短信为什么没有发出？

1. 平台短信开关/密钥未配置（全局）  
2. 营销规则未审批（`approved_at`）或未开自动执行  
3. 模板审核中 / 运营商拒绝  
4. 客户号码无效或日频控拦截  

## coupon-not-redeemed · 优惠券为什么没有核销？

1. 券未到账或已过期  
2. 店员未在小程序核销，或核销后未在 POS 登记  
3. 核销事件未回流 HRMS（看出站队列/同步失败）  

## report-calc · 报告数据如何计算？

1. 营收类以 `pos_sales_detail` / `pos_order_items` 为准，不用残缺的订单头表单独对账  
2. 人工日报 `daily_reports` 与 POS 交叉验证，误差通常 &lt;0.5%  
3. 具体指标口径见指标字典；有争议先对口径再对数字  

## pos-source · 哪些数据来自 POS？

订单明细、菜品、金额、折扣、结账时间、部分手机号/会员字段。会员授权手机号、券核销、扫码归因来自小程序/增长事件。

## ai-auto-execute · AI 建议是否会自动执行？

默认多数经营建议需确认；营销触达仅在规则已审批且开启自动执行时才会发。未确认/未执行会记入任务闭环，月报复盘可说明「系统已建议但客户未执行」。

## system-unavailable · 系统为什么显示不可用？

看功能可用性与阻塞项：缺门店、缺 POS、缺客户数据时，经营诊断/自动营销/月度复盘会标「不可用」或「部分可用」。先消红项，再谈功能。

## add-store-staff · 如何添加门店和员工？

租户管理员在 HRMS 后台维护门店与员工；平台侧开通租户后需完成验收。未绑定门店岗位会导致任务无法派发（健康中心会标红）。
