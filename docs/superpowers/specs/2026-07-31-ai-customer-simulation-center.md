# AI 客户模拟训练中心（AI Customer Simulation Center）开发计划

> 状态：P0–P3 代码已落地（2026-07-31）——待全面测试  
> 迁移：`169_sales_sim_center.sql` + `170_sales_sim_p1_p3.sql`  
> 入口：`platform-admin` 模拟训练 / 独立页 `sales-sim.html` / 租户 API `/api/sales-sim/*`  
> 定位：AI Sales / CS Training OS——训练高成交销售与高满意度客服，不是普通聊天陪练  
> 归属：GAAS 销售域（`server/domains/sales-sim/` + `platform-admin` / 后续 `sales-sim.html`）  
> 不进：`working-fixed.html`、`agents-admin.html`、agents-service-v2

---

## 1. 产品目标

训出能适应变化的销售与客服，而不是会背台词的人。

终极形态四个闭环：

1. **AI 客户模拟**：无限真实客户场景（人格 + 情绪 + 业务真题）
2. **AI 实时教练**：每一句即时旁白反馈
3. **AI 复盘指导**：结构化评分 + 思维框架纠偏 + 优秀话术参考
4. **AI 能力成长 / 职级引擎**：按训练时长与结果晋级（普通→资深→金牌/销冠→导师）

---

## 2. 轨道与身份（Track）

同一个「训练中心」入口；**开场必须选择轨道**，整场锁定。

| Track | 默认来源（可改） | 成功标准 |
|-------|------------------|----------|
| `sales` 销售陪练 | 账号岗位 `sales` | 成交就绪分 + 四项底层能力 |
| `cs` 客服陪练 | 账号岗位 `customer_service` / `implementation` | 满意度 + 解决闭环 + 情绪安抚 |

- 账号岗位只做**默认选中**，不负责猜身份。
- 题库、评分、职级、话术库均按 Track 隔离。

## 3. 指导哲学：两层结构（已确认）

> 销冠厉害的不是说了哪句话，而是知道**什么时候说什么话**。  
> 只学固定话术 → 背台词 → 一变就不会。

### 3.1 采用的两层模型

| 层 | 名称 | 作用 | AI 行为 |
|----|------|------|---------|
| **L1** | 思维框架（Principles） | 始终坚持的判断标准 | 每轮/每场强制检查是否违反 |
| **L2** | 优秀话术（Exemplars） | 举例参考，非标准答案 | 给出 1～2 条可替换说法，标注「参考」与来源 |

**补充约定（实现时必须遵守）：**

1. **时机优先于措辞**：复盘先写「在什么时刻违反了哪条原则」，再给参考话术。  
2. L2 话术一律标注 `参考·来源`，禁止标成「唯一正确答案」。  
3. 学员用不同措辞但符合 L1 → **算对**；只会背 L2 原句但时机错误 → **算错**。  
4. 实时教练默认只推 L1 标签（如「过早讲产品」）；L2 参考话术主要放赛后，避免边聊边背稿。

### 3.2 销售 L1：五条核心原则（AI 指导标准）

每场结束后强制检查：

1. **不急着介绍产品** —— 先问「现在最想解决什么」  
2. **不卖功能，只卖结果** —— 功能问法要拉回业务结果优先级  
3. **一直围绕客户痛点** —— 价格异议先挖真实顾虑  
4. **永远先提问** —— 避免连续独白；可要「先问三个问题」许可  
5. **不和客户争论** —— 先承认对方有原因，再追问经历  

### 3.3 销售四项底层能力（持续评分主轴）

| 能力 | 英文 | 考什么 |
|------|------|--------|
| 提问 | Questioning | 高质量问题、引导真实需求 |
| 倾听 | Listening | 抓住关键信号，不急于回应 |
| 价值表达 | Value Communication | 能力 → 客户能懂的业务价值 |
| 成交推进 | Closing | 购买信号、异议、下一步行动 |

> 产品知识正确性作为**合规闸门**（答错可阻断「成交成功」结局），但不替代上述四项成为唯一分数。

### 3.4 客服 L1：金牌原则（与销售对称）

1. **先安抚再处理** —— 抱歉 + 承诺先办 + 办完再解释  
2. **共情情绪** —— 站在客户立场，不说空话「别着急」  
3. **探询期望** —— 功能不满时问「希望怎么操作」  
4. **退款/升级先挖根因** —— 不直接硬挡，先问未达预期之处  
5. **闭环交付** —— 是否解决、是否说明原因、是否约定回访  

客服四项底层能力：

| 能力 | 考什么 |
|------|--------|
| 情绪安抚 | Empathy |
| 问题定位 | Diagnosis |
| 解决闭环 | Resolution |
| 关系维护 | Retention（愿否继续合作） |

### 3.5 销售 L2：系统向优秀话术库（举例，非背诵稿）

入库场景（首批，可扩展）：

| 场景 key | 客户触发 | 参考方向（摘要） |
|----------|----------|------------------|
| `has_system` | 我已经有系统了 | 问「缺系统」还是「数据没人用」 |
| `too_expensive` | 太贵了 | 软件成本 vs 30 天经营改善的投入 |
| `think_again` | 再考虑一下 | 问清顾虑：预算 / 效果 / 需与他人沟通 |
| `no_time` | 没时间 | 忙更值得减负，而非加负担 |
| `ask_features` | 有什么功能 | 拉回「客流/执行/复购」何者最重要 |
| `ai_useless` | AI 没用 | 先问过往踩坑经历，不争论 |

完整参考句见附录 A；入库字段见 §7。

### 3.6 客服 L2：金牌话术库（举例）

| 场景 key | 触发 | 参考方向 |
|----------|------|----------|
| `complaint` | 投诉 | 抱歉 → 先处理 → 再说明原因 |
| `angry` | 情绪不好 | 共情「换我也会急」→ 一起处理 |
| `ux_bad` | 功能不好用 | 感谢建议 → 问期望操作 |
| `refund` | 想退款 | 理解 → 挖未达预期原因 → 先谋解决 |

完整参考句见附录 B。

### 3.7 赛后结构化反馈模板（强制格式）

```
本场评分：{score} 分
轨道：销售 | 客服
职级进度：{rank} · 距下一级 {gap}

优点：
- …

需要提升（按原则/能力，带原话时间点）：
1. [原则② 不卖功能] 客户问功能时，你在第 4 轮开始罗列模块……
2. …

建议替代表达（L2 参考，非唯一答案）：
❌ 原回答：…
✅ 参考：…  （来源：销冠话术 · too_expensive）

本场能力雷达：提问 / 倾听 / 价值表达 / 成交推进（或客服四项）
下一场推荐：{persona} × {objection} × 难度 Lv{n}
```

## 5. 职级与升级体系（新增，已纳入）

### 5.1 职级阶梯

**销售轨**

| 职级 key | 显示名 | 定位 |
|----------|--------|------|
| `sales_rookie` | 普通销售 | 入门，熟悉原则与基础异议 |
| `sales_senior` | 资深销售 | 稳定应用四项能力 |
| `sales_ace` | 销冠 | 高难度人格下仍能推进 |
| `sales_mentor` | 导师销售 | 可带教；话术可晋升入库 |

**客服轨**

| 职级 key | 显示名 | 定位 |
|----------|--------|------|
| `cs_rookie` | 普通客服 | 入门安抚与工单闭环 |
| `cs_senior` | 资深客服 | 情绪与定位稳定 |
| `cs_gold` | 金牌客服 | 高难度投诉/退款仍达标 |
| `cs_mentor` | 导师客服 | 可带教；金牌话术可晋升入库 |

两轨职级**独立计算**（同一人可以是销冠 + 普通客服）。

### 5.2 升级依据（训练时间 × 训练结果）

升级看三类指标，缺一不可：

| 维度 | 含义 | 示例门槛（可配置，上线前用种子数据校准） |
|------|------|------------------------------------------|
| **有效训练时长** | 完成场次的累计分钟（中途放弃不计） | 普通→资深：≥ 120 分钟 |
| **能力达标** | 近 N 场四项（或客服四项）均分与最低分 | 均分 ≥ 75，单项 ≥ 60 |
| **难度通关** | 在指定难度连续达标场次 | 资深→销冠/金牌：Lv5+ 连续 3 场 ≥ 80 |

附加规则：

- **冷却**：同一天刷分，每日计入有效场次有上限（防刷级）。  
- **回退**：连续 M 场低于职级保级线 → 降一级（导师另议，默认只警告）。  
- **导师额外条件**：除分数外，需主管标记「可带教」，或贡献 ≥ K 条被采纳的 L2 话术。  
- **证书展示**：CRM / 训练中心展示当前职级徽章与雷达；接入现有销售行为分（训练权重已有 25%）时可只读职级，不反向污染真实提成。

### 5.3 职级 × 课表

| 职级 | 默认解锁内容 |
|------|----------------|
| 普通 | Lv1–3 人格；核心原则教学场 |
| 资深 | Lv4–6；复合异议（预算+决策链） |
| 销冠/金牌 | Lv7–10；沉默/打断/最后一分钟反悔 |
| 导师 | 旁观学员场次、批注、提名话术入库 |

## 6. 分阶段交付

### P0 — 验证（约 2–3 周）

- Track 选择（销售 / 客服）  
- 5 销售人格 + 3 客服场景，多轮文字对练  
- L1 原则检查 + 结构化复盘（含 ❌/✅ 参考话术）  
- 首批 L2 话术入库（附录 A/B）  
- 职级模型落库 + 普通→资深 一条可跑通的升级规则  
- UI：`platform-admin`「模拟训练」面板  
- 成功标准：主观「像真客户」≥ 4/5；复盘「可指导下场」≥ 4/5  

### P1 — 内部日练（约 4–6 周）

- 情绪 / 挂断 / 成交就绪分（训练分，非预测）  
- 实时教练旁白（L1 标签）  
- 半双工语音  
- 完整四阶职级 + 保级/防刷  
- 能力雷达与下一场自动出题  
- 评估拆独立页 `sales-sim.html`  

### P2 — 客服轨加深 + 语料飞轮

- 客服高难度投诉/退款  
- 真实赢单/高满意度会话 → 候选 L2 → 主管晋升  
- 导师带教视图  

### P3 — 产品化护城河

- 经营数据真题人格（复购率/POS/诊断）  
- 租户侧训店员（再考虑迁入员工培训域）

## 8. 质量闸门与验收

1. 人格前后矛盾率 &lt; 5%  
2. 复盘 Top3 问题与主管盲评一致 ≥ 80%  
3. L2「销冠/金牌」标签 100% 有来源；禁承诺零漏网  
4. 符合 L1 但措辞不同于 L2 → 判分不得因「没背原句」而扣分  
5. 职级升级可复现（同一会话日志重放 → 同结果）  
6. 防刷：日有效场次上限生效

## 附录 A — 销售优秀话术（首批入库文本）

### 原则示例

- 介绍前：`在介绍之前，我想先了解一下您现在最想解决的是什么问题？`  
- 功能问法：`我先不讲功能，我想问一下，如果未来三个月客流增长20%、员工执行更稳定、老客户复购提升，哪个对您最重要？`  
- 太贵：`我理解价格是需要考虑的。我想确认一下，如果这套服务一年能帮您多带来几十万营业额，您更担心价格，还是担心达不到效果？`  
- 先提问：`我可以先问您三个问题吗？`  
- AI 没用：`您这么说一定有原因，方便说说之前遇到过什么情况吗？`  

### 系统场景

- 已有系统：`很多客户第一次也是这么说。其实我想了解一下，您现在最大的困扰，是系统没有，还是系统里的数据没人真正利用？`  
- 太贵（完整）：`我完全理解。如果只是买一个软件，我也会觉得贵。我们更关注的是，未来30天能不能让您看到经营上的改善。如果没有价值，再便宜也是浪费；如果能持续带来收益，它就不是一笔成本，而是一项投入。`  
- 再考虑：`没问题。为了避免我后续给您带来不必要的打扰，我想确认一下，您现在最大的顾虑是什么？是预算、效果，还是还需要和其他人沟通？`  
- 没时间：`正因为您忙，所以才更值得看看。我们希望减少您每天花在管理和分析上的时间，而不是增加工作量。`  

## 附录 B — 客服金牌话术（首批入库文本）

- 投诉：`非常抱歉给您带来困扰，我先帮您把问题处理好，处理完成后我再跟您说明原因，可以吗？`  
- 情绪：`我理解您现在着急，如果我是您，遇到这个情况也会着急。您放心，我现在跟您一起处理。`  
- 不好用：`谢谢您提这个建议。方便告诉我，您当时希望它怎么操作吗？这样我可以准确记录，也看看有没有更适合您的使用方式。`  
- 退款：`我理解您提出退款一定有原因。能不能先告诉我，是什么让您觉得这套服务没有达到您的预期？如果确实是我们的问题，我们先一起想办法解决。`
