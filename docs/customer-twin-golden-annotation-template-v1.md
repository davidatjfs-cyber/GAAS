> 填写人：业务专家/店长。以下模板按你给的 Case 结构做好，**示例为草案，所有"判断"字段待你确认/修改**。

## 一、每组 Case 的填写结构（15 项）

```
case_id / title / difficulty / purpose
├─ 1 客户人格：visit / intent / price / service / environment / food / expression / complaint / recovery
├─ 2 消费背景：时间 / 人数 / 首访复访 / 种草渠道 / 预算 / 目的
├─ 3 消费目标：聊天 / 拍照 / 体验 / 安静 …
├─ 4 事件时间轴 Timeline：进店→落座→点菜→上菜→催菜→处理→买单
├─ 5 每一步心理变化：情绪连续曲线（85→74→61…，禁止跳变）
├─ 6 标准反馈：分阶段话术（第一次委婉→第二次质疑→第三次取消→沉默）
├─ 7 标准吐槽：真实表达（不是"菜慢"，而是"隔壁桌比我们晚来都上齐了"）
├─ 8 不能说的话 negative：禁止戏剧化（报警/曝光/辱骂/突然离店）
├─ 9 点菜行为：浏览→问招牌→问分量→犹豫→接受/拒绝推荐
├─ 10 推荐接受率：服务员推荐什么接受 / 拒绝
├─ 11 补偿恢复：每次动作恢复值（解释+5 / 经理+12 / 甜品+8），恢复≤原始损失
├─ 12 最终满意：拆分明细（菜/服务/环境/等待/补偿 → 总分）
├─ 13 最终行为：是否投诉 / 点评 / 星级 / 复购 / 推荐
└─ 14 专家解释：为什么是这个结果
（15 四层标注：L1 行为层 / L2 心理层 / L3 语言层 / L4 判卷层 对应上面的客观行为/情绪曲线/标准话术/合格与失真标准）
```

## 二、示例 Case（G_TV_5508d9f9 食安事件，草案待确认）

**基础信息**：case_id G_TV_5508d9f9｜title 食安事件（蟑螂+苍蝇）与完整恢复｜难度 4｜purpose 测试食安事件 + 恢复链 + 不写差评诉求

**客户人格（草案）**：visit 首次到店（大桌/高消费 2802 元）；intent 家庭/聚餐；price 中等敏感；service 高敏感；environment 高敏感（食安零容忍）；food 高；expression 委婉；complaint 低（给机会）；recovery 高（真诚处理可恢复）

**消费背景**：日期 2026-12-08｜洪潮大宁久光店｜多人聚餐（包房）｜消费 2802 元

**消费目标**：体验 / 聊天 / 吃好（对菜品包房满意）

**事件时间轴**：
1. 入座点菜（满意起点 85）
2. 等待上菜时 v1 桌跑出蟑螂（情绪 → 55）
3. 门店抓到拿走 + 真诚道歉 + 送 2 热菜 / 2 冻柠茶 / 2 奶冻（→ 68）
4. 餐中飞进苍蝇在 v2 转（→ 58）
5. 客人点单的菜打折 + 再次道歉（→ 70）
6. 领导出面"给改正机会、别写差评"（→ 72）
7. 买单离店（最终满意约 72-75）

**标准反馈（草案）**：第一次"桌上有蟑螂，这怎么吃饭？"→ 处理后再现苍蝇"怎么又有苍蝇？"→ 打折道歉后"这次就算了，但卫生你们真得管管"

**标准吐槽（草案）**："菜是好吃的，就是这卫生让人心里发毛，一晚上又是蟑螂又是苍蝇。"

**不能说的话（negative）**：不会直接报警/曝光/辱骂/离店；不会说"以后再也不来"（因为给了补偿且领导诚恳）

**点菜行为 / 推荐接受率（草案）**：高消费桌，接受热菜/饮料补偿；对"不要写差评"的要求未直接承诺

**补偿恢复（草案）**：解释+5｜热菜饮料+12｜打折+10｜领导致歉+8｜恢复总额 ≤ 原始损失

**最终满意拆解（草案）**：菜 40 / 服务 25 / 环境 8 / 等待 -5 / 补偿 +12 → 80（待确认）

**最终行为（草案）**：不投诉现场；点评未写差评（按原文）；复购：会（"给改正机会"）；推荐：一般

**专家解释（草案）**：食安是底线事件，但补偿链完整 + 领导诚恳，情绪从 55 恢复到 72；最终不会五星，也不会差评——"给机会"但记忆还在。

**四层标注对应**：L1 行为=时间轴客观事件；L2 心理=情绪曲线 85→55→68→58→70→72；L3 语言=标准反馈/吐槽；L4 判卷=以上"标准答案"与"不能说的话"。

## 五、判卷总则与恢复上限（2026-08-05 专家修订，已按此入库）

黄金基准集按 Ground Truth 标准编写（不是培训教材），四条总则：

1. **情绪连续**：不能大起大落；
2. **符合真实消费者心理**：不能为了剧情而剧情；
3. **行为可判卷**：AI 能判断是否一致；
4. **恢复效果有限**：餐饮不存在"送两个菜就完全恢复"。

### 5.1 Recovery Ceiling（恢复上限，新增判卷字段）

| 事件类型 | 恢复上限 |
|---|---|
| 食安 | 最高 65 |
| 服务态度 | 最高 60 |
| 招牌售罄 | 最高 58 |
| 菜品口味 | 最高 70 |
| 催菜 | 最高 85 |

约束：任何恢复都不得让满意度突破对应事件类型的恢复上限（"送一份甜品从 40 恢复到 90"即失真）。引擎已按此实现（`RECOVERY_CEILING`）。

### 5.2 三个已批准案例的修订要点

**G_TV_5508d9f9 食安（S 级）**
- 情绪曲线：85→**35**→55→**42**→58→**62**（首现蟑螂是底线事件，接近 -50；苍蝇再现是"验证卫生有问题"，而非新事件；恢复只到 62，卫生记忆不消失）；
- 标准反馈：先"服务员，这边有只蟑螂/麻烦过来看一下"，处理后才"说实话这样真的影响胃口"，苍蝇再现才"怎么又来了？"，结尾"菜其实不错，就是卫生这块一定得整改"；
- 恢复动作：立即处理异物+8、负责人道歉+6、赠菜饮品+5、打折+4、领导沟通+4（最多 +27）；
- 最终满意：菜38/服务27/环境8/等待18/补偿+8 → 63~66；
- 判卷规则：**食安属底线型事件，任何补偿只能减轻情绪、无法消除风险记忆；恢复后满意度不得高于事件发生前水平的 80%**。

**G_BR_c3869c2e 服务态度**
- 情绪曲线：80→72→**58**→**48**→**42**（掉分快的是态度本身，不是"桌子没擦"）；
- 标准反馈：从"麻烦帮我们擦一下桌子，谢谢"到"烟灰缸也麻烦一起收一下"到"是不是我们哪里让你不高兴了？"到"如果一直这样，我们这顿饭体验真的很差"（真实顾客不会一开始就质问）；
- 恢复：经理 2 分钟内主动换服务员 +10；经理未出现 0（态度问题必须换人）；
- 判卷规则：**态度冲突后若仍让原服务员继续服务，判定为失真**。

**G_BR_355da999 招牌售罄**
- 新增期望字段：今天来店原因=**专门为了烧鹅**；
- 情绪曲线：82→**52**→**38**→**32**（专门来吃，第一下就 -30）；
