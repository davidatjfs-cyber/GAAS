# 数字孪生盲测问卷 v1

> 目的：验证孪生生成的顾客反馈是否"像真人"（L2 门槛）。
> 做法：以下 20 条反馈中，10 条来自真实顾客（差评原文），10 条由孪生引擎生成，已混排。
> 判断者：建议 3-5 人（老板/店长/老服务员各 1+），**不要先看答案**。
> 判定标准：孪生条目的"像真人"平均分 ≥ 4/5 且判断正确率 ≤ 60%（基本靠猜）→ 通过，值得全投；3-4 分 → 定位改进；< 3 分或正确率 > 80% → 停下复盘。

## 填写说明

对每条反馈做两件事：
1. 判断「真人说的 / AI 生成的」；
2. 给"像不像真人"打分：1=一眼假，2=不太像，3=说不清，4=挺像，5=完全像真人。

## 统计方式（判断者填完后交回，我来统计）

1. 正确率 = 判断错误条数 / 20（认错越多 = 越分不清 = 孪生越像）；
2. 孪生条目平均"像真人"分（答案 key 里的孪生条目单独算）；
3. 若某条被 2 人以上"一眼假"，单独列出来定位问题（心理层/语言层/数据层）。
