# 餐厅AI增长服务客户演示片

约 144 秒、16:9 客户演示故事版。叙事以餐饮老板的一天为主线，每个场景按“痛点发生 → 损失显现 → 系统介入 → 结果改变”展开。

## 预览

```bash
npm install
npm run dev
```

## 渲染

```bash
npm run render
```

输出文件：`out/restaurant-ai-growth-story-v2.mp4`

## 素材原则

- 产品画面使用真实系统脱敏截图或录屏。
- 案例数字标明为现有系统单次营销归因示例。
- 不承诺固定营业额增长。
- 正式配音与配乐加入后，再按音频时长微调各场景节奏。
